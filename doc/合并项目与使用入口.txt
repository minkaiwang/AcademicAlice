【本分支相对「桌宠与工作台分开使用」的主要差异（概要，非功能承诺）】

- 同一进程：桌宠与科研工作台共用托盘 / 命令面板；论文、项目、任务等工作台数据在浏览器内管理，
  减少「再开一个浏览器标签」的上下文切换。
- 产品与人设：爱弥斯（学术桌面助手），人格见 resc/persona.txt；对外名以 app_brand.py
  为准。
- 专用聊天窗口：命令提示里「与爱弥斯聊天」打开独立窗口，发送仍走与桌旁气泡相同的
  聊天管线；界面为粉系与主 UI 一致。
- 数据以本地为主；工作台 localStorage 键名见 PROGRESS.md / workbench README（勿随意改
  以免丢配置）。

【必读操作入口】

- 启动：解压后保持文件夹完整，运行主程序（见 README 下载与安装）。
- 科研工作台：从应用内菜单 / 托盘等入口打开（以当前版本 UI 为准）；断网时图表等外链
  可能不可用。
- 文档：根目录 README.md（GitHub 式总览）、PRODUCT.md（品牌与中文口径）、PROGRESS.md
  （里程碑与技术 SSOT）；浏览器打开 AA使用必读.html 可查阅贡献原文与 doc/*.txt（门户由脚本生成，
  不含赞助/打赏展示）。
